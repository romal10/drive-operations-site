# Drive Operations

Vehicle transfer management and invoicing for clients and drivers.

- **Web app (live):** https://drive-operations.expo.app
- **Website with screenshots and install guide:** https://romal10.github.io/drive-operations-site/

Install on iPhone via Safari (Share → Add to Home Screen), on Mac/Windows via Chrome or Edge (install icon in the address bar). Accounts are approved by the administrator before first use.
