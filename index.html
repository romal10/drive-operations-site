How it works

Three steps from order to payout. The app interface is currently in German.

STEP 1

Register & invite

A client company signs up, sets its price list and invites drivers with a username and start password. Accounts are reviewed before they can use the platform.

STEP 2

Assign & drive

Create or scan orders and hand them to a driver. Drivers accept, drive, and photograph fuel and parking receipts. OCR runs on the device, no connection needed.

STEP 3

Settle & invoice

Distance is priced from the client's price list, retention is applied to the distance price only, driver-paid receipts are refunded. Export invoices as PDF and Excel.

iPhone & iPad via Safari

There is no App Store version. Install the web app instead:

  1. Open the web app in Safari
  2. Tap Share
  3. Choose Add to Home Screen

Android APK

Direct download (test build). You may need to allow installs from your browser.

Download APK

Or open the web app in Chrome → menu → Install app.

Mac & Windows install from browser

There is no separate installer; the web app installs as a desktop app:

  1. Open the web app in Chrome or Edge
  2. Click the install icon in the address bar (or menu → Install)
  3. Launch it from your Dock, Start menu or Launchpad

Built for settlement you can trust

  • Photo capture of orders and receipts, offline OCR
  • Price per distance band, per client price list
  • Retention applied to the distance price only
  • Driver-paid receipts refunded, client-paid listed only
  • Role-based access: drivers only see their own work
  • Encrypted transfer, data synced to the cloud
  • Reports by day, week, month and driver
  • Invoices as PDF and Excel
